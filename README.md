## 🧠 Projetos SA:MP

### 🌍 [Formosa PvP](https://www.formosamp.com.br)
O servidor **PVP**, em desenvolvimento mas já disponível para jogar/testes, com foco em oferecer as melhores opções de treinos e batalhas épicas nas trocações, experiência imersiva com todo uso de textdraws simulando imagens, fácil acesso aos androids, com sistemas surpreendentes incluindo comunicação por voz, uso de teclas substituindo comandos, usamos como exemplo o **Foguete PvP** do fivem para desenvolver as criatividades do projeto Samp..

### 🌍 [Formosa Roleplay](https://www.formosamp.com.br)
Os servidores Formosa, uma rede com três servidores, o  servidor Roleplay em desenvolvimento com foco em realismo, jogabilidade envolvente e sistemas bem estruturados, voltado para quem busca uma experiência completa e imersiva. O projeto está sendo construído com atenção aos detalhes para oferecer conteúdo original, economia balanceada e comunidade ativa, usando como foco projetos do fivem, pensando também nos dispositivos móvel para atrair esses players..
